# fix-failing-test

Следуйте [AGENTS.md](../../../AGENTS.md).

Прочитайте [диагностику](../../../knowledge/testing/debugging.md) и сохраните оригинальные
логи/артефакты до повтора. Найдите failing phase и актуальную реализацию Page Object/fixture.
Учитывайте Python 3.13 local-browser в Actions и Python 3.14 remote-browser в Jenkins,
ru/en текст ошибки входа и постоянные данные регистрации.
Классифицируйте причину по свидетельствам. Не удаляйте remote-конфигурацию, не меняйте
стек и не ослабляйте checks ради результата. Исправьте подтверждённый дефект в рамках
задачи и повторите тот же минимальный scope. Flake требует ограниченных повторов и
сравнения данных. Сообщите доказанную причину либо гипотезу, изменения и результаты проверки.
