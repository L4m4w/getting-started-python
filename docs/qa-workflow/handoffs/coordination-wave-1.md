Дата: 2026-11-14. Пилот: CAT-UPD-VAL.

## Решение по 00

Ревью принято. M-1–M-3 внесены в scenarios.md без изменения R1–R4:
повторный GET до assertions негативного сценария; тело PATCH — вторичный
контракт; проверка коллизий имён и очистка собственной категории строго по ID.
Это решение координатора по реализации согласованного пилота.

Поправка к отчёту 00: «все негативные случаи на base возвращают 200 и
сохраняются» — вывод из исходников, а не наблюдение HTTP-прогона.
Фактическое поведение ещё предстоит проверить. У spend есть бизнес-проверки;
на просмотренном пути обновления отсутствуют именно проверки пустоты/длины.

## Решения по реализации

- Python API-тесты: текущий `getting-started-python/tests/api/`, минимальный
  транспорт `infrastructure/http/`. Учебный framework целиком не переносится.
- JWT и точечная очистка — задача 03. Создание категории через публичный POST
  предпочтительно, применимость и контракт проверяет 03.
- Эти вопросы блокируют конкретные E2E fixtures, но не standalone MockMvc.
- Не добавлять spring-security-test заранее: сначала custom Jwt resolver.
  Новую зависимость можно добавить только при обоснованной необходимости.

## Интеграция 02

Независимое ревью выявило две проблемы: при interrupt дочерний процесс не
останавливался до финализации manifest; повреждённый XML мог молча исключаться
из общей сводки при наличии другого читаемого XML. Дополнительно cleanTest
не гарантирует отсутствие FROM-CACHE. Исправления интегрированы:

- Собственная POSIX process group завершается и ожидается перед фиксацией
  interrupted. Остановка чужих процессов не выполняется.
- Повреждение любого XML делает сводку недоступной (`summary=null`),
  исходные XML сохраняются.
- Gradle получает `--no-build-cache --rerun-tasks --no-daemon`;
  cleanTest остаётся. Реальный запуск harness на Java ещё не выполнен.
- Добавлены 3 проверки; Java harness unit-набор теперь содержит 13 случаев.
- Координатор выполнил `sh tools/compile-tests.sh` (55 collected, exit 0),
  `sh tools/run-tests.sh group unit` (46 passed, 0 failed/errors/skipped,
  exit 0) и whitespace check. Python 3.13.15, pytest 9.1.1.
  Evidence: `artifacts/harness/run-4btiiumq/` (manifest, JUnit, Allure).

Проверки process termination пока выполнены на подменах, не на реальном Gradle.
Обновлённая команда готова для первого реального прогона агента 04.
Исходный handoff 02 сохраняется как история передачи, актуальное поведение
после исправлений описывается в knowledge/testing/run-tests.md.
