# Агент 02: evidence для Java-эксперимента

Расширь локальный harness для воспроизводимого запуска одного Java-теста
пилота. Других агентов не запускай.

## Цель и действия

Подготовь отдельную команду Java-прогона: входы — путь репозитория приложения,
JDK, selector теста и метка baseline/head. Сначала согласуй интерфейс с
координатором, чтобы его передали агентам 04/05.

Каждый запуск должен иметь свежий evidence-каталог: UTC-время, версии,
SHA/dirty, точную безопасную команду, exit code, копии JUnit и сводку.
Если код незакоммичен, сохрани идентичность теста и целевых исходников через
хеши и/или ограниченный patch; не собирай весь репозиторий и env.
При сбое запуска, отсутствии JUnit или пропуске выполнения отчёт должен это
показывать. Не используй старый XML и не объявляй cached/UP-TO-DATE за новый
фактический прогон. Сохраняй ожидаемый ненулевой результат baseline.

## Проверка и готовность

Добавь содержательные проверки на launch failure, stale/missing JUnit,
изоляцию запусков и сохранение ненулевого exit code. Используй подмены
процесса без сети, Java и приложения. Соблюдай конвенции Allure и констант.
Выполни подходящие локальные проверки и сообщи результаты.
Gradle в реальном приложении в этой задаче не запускай — это делает 04/05.
Передай рабочую команду, контракт манифеста, тестовые результаты и предложения
для каталога компонентов. Не скрывай частично реализованные требования.
