1. Для API-прогона фиксируй до старта pytest хеши/копии согласованного набора

2. Подготовь явный способ приложить метаданные окружения: base SHA + patch

   Не сохраняй env/credentials или полный Docker inspect. Декларацию
   оператора различай с фактическим результатом проверки контейнера.
3. Обнови runbook 07: привязка контейнера к image ID до каждого base/fix

   некорректных metadata. Старые команды unit/UI/Java должны сохраниться.
