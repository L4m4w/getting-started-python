# Проверки и стиль

Следуйте [AGENTS.md](../../AGENTS.md) и ближайшему реальному сценарию.
Page Objects содержат локаторы/действия, методы действий размечаются @allure.step.
В тесте проверка находится внутри with allure.step; direct driver calls не добавляются.

Используйте существующие WebDriverWait / expected_conditions. Не добавляйте sleep,
не ослабляйте ожидаемый результат и не меняйте продукт ради зелёного теста.
Количество проверок определяется требованиями сценария, а не числом строк в примере.
Не добавляйте дублирующие ожидания без причины; отдельные необходимые условия допустимы.

В текущем negative-login сценарии ждут видимость сообщения, непустой текст и затем
проверяют один из двух точных локализованных вариантов. Это существующая реализация,
не универсальный шаблон для новых проверок. При рефакторинге учитывайте stale element.
